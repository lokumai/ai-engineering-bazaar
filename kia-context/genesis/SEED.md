# 🌰 SEED — The first prompts

## These are gone, and cannot be recovered

The project started on **2026-07-07**. The context harness was installed on **2026-09-08**, two months
and 105 commits later. The conversations from that first session are not in this repository and are not
in any agent's memory.

**Nothing has been reconstructed here on purpose.** An invented first prompt is a fabricated historical
record, and it would be believed. The git history can tell you what the first commits contained — the
first modules were LLMs, RAG, tools and memory, published with a documentation generator — but it
cannot tell you what was asked for, and that is the only thing this file is for.

## Two ways to finish this file

**Paste them.** If the original conversations still exist anywhere — a saved chat, a transcript, a
notes file — paste them and an agent will clean them up lightly and record them here with their dates.

**Or delete this file.** An absent `SEED.md` is honest. `kia-context/INDEX.md` should lose its row at
the same time, and `genesis/GENESIS.md` already carries what is actually known about why the project
started.
