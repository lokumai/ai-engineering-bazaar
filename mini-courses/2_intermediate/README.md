# Intermediate

Once the fundamentals are solid, these modules cover the craft of actually building good agents: prompting, context, coding agents, harnesses, security, and more.

Every claim in these modules is cited to a primary source that was fetched and checked, and each module ends with a **References** section. These topics mostly changed within the last year, so go and read the source when it matters.
