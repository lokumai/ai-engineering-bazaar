# Intermediate

Once the fundamentals are solid, these modules cover the craft of actually building good agents: prompting, context, coding agents, harnesses, security, and more.

Every claim in these modules is cited to a primary source that was fetched and checked, and each module ends with a **References & Further Reading** section — these topics mostly changed within the last year, so go read the source when it matters.

> **Most Turkish translations are still placeholders.** Module 8 is translated in full; the remaining `_tr.md` files are being translated in a separate pass, each one after its English module is final.
