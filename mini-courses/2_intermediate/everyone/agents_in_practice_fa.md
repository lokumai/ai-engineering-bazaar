# Agent‌ها در عمل

یه AI agent فقط به سؤالت جواب نمی‌ده؛ برات کار هم انجام می‌ده. فایل باز می‌کنه، سند می‌نویسه، توی اینترنت می‌گرده و از اپ‌هات استفاده می‌کنه، قدم‌به‌قدم، تا وقتی که یه کار تموم بشه. می‌تونی کلی درباره‌ی agent‌ها بخونی، ولی سریع‌ترین راه برای فهمیدنشون اینه که یه کار واقعی بدی دست یکی‌شون و ببینی چی کار می‌کنه.

> [!WARNING]
> **🛑 ایست. اول دوره‌ها رو بگذرون، بعد برگرد این‌جا.**
>
> درس اصلی این صفحه نیست. این صفحه تو رو می‌فرسته سراغ سه تا دوره‌ی رایگان، و یاد گرفتن واقعی موقع گذروندن همون دوره‌هاست. دوتاشون الزامی‌ان و روی هم حدود پنج ساعت طول می‌کشن: Claude 101 و Introduction to Claude Cowork، هر کدوم حدود دو ساعت و نیم. سومی، Claude Code 101، اختیاریه و حدود یه ساعت و نیم بهش اضافه می‌کنه.
>
> ⏱️ الزامی‌ها حدود پنج ساعت · ➕ اختیاری حدود یه ساعت و نیم
>

## چرا این دوره‌ها رو بگذرونی

وقتی درباره‌ی یه agent می‌خونی، همه‌چی خوب پیش می‌ره. ولی وقتی باهاش کار می‌کنی، بعضی وقت‌ها منظورت رو اشتباه می‌فهمه یا راه رو کج می‌ره، و اون‌وقت تو باید متوجه بشی و به مسیر درستش برش گردونی. مهارت اصلی همینه، و فقط با تمرین یاد گرفته می‌شه.

سه تا دوره‌ی پایین رایگان و کوتاهن، و با انجام دادن یاد می‌گیری. همون شرکتی که این ابزارها رو ساخته نوشتنشون، و ته هر کدوم یه quiz کوتاه و یه نشان (badge) هست.

هر سه‌تاشون از ![](../images/logos/claude.svg)**Claude** استفاده می‌کنن، دستیار هوش مصنوعی‌ای که Anthropic ساخته. ما فکر می‌کنیم الان، موقع نوشتن این متن، برای این جور کارها از همه توانمندتر، قابل‌اعتمادتر و پرامکانات‌تره. هر چی هم باهاش یاد بگیری، با بقیه‌ی دستیارهای هوش مصنوعی هم به کارت میاد.

## Claude 101

> [!IMPORTANT]
> **🛑 دوره‌ی اول از سه تا: همین‌جا وایسا و الان بگذرونش**
>
> **Claude 101**: Claude برای کارهای روزمره: اولین گفت‌وگو، جواب‌های بهتر، و project‌هایی که یه کار رو یک‌جا نگه می‌دارن.
>
> ⏱️ حدود دو ساعت و نیم · ✅ الزامی · 🏅 دوره‌ی رایگان، با یه quiz و یه نشان
>
> دوره رو باز کن، تمومش کن، بعد برگرد این‌جا و ادامه بده.
>
> **[رفتن به دوره‌ی Claude 101](https://academy.claude.com/courses/claude-101)**

[Claude 101](https://academy.claude.com/courses/claude-101) جاییه که همه باید ازش شروع کنن. نشونت می‌ده Claude رو چطور توی کارهای روزمره‌ت به کار ببری: اولین گفت‌وگوت، این‌که چطور بپرسی تا جواب بهتری بگیری، و این‌که چطور سندها و دستورهای مربوط به یه کار رو توی یه project کنار هم نگه داری. این رو هم نشون می‌ده که Claude چطور به ابزارهایی که الان ازشون استفاده می‌کنی وصل می‌شه.

یه حساب Claude لازم داری؛ پلن رایگان هم کافیه و هیچ تجربه‌ای با هوش مصنوعی لازم نیست. فقط اگه بخوای بخش‌های Cowork و Research رو خودت امتحان کنی، پلن پولی لازم داری. حدود دو ساعت و نیم طول می‌کشه.

## Claude Code 101 (اختیاری)

> [!NOTE]
> **💡 دوره‌ی دوم از سه تا: اختیاریه، اگه کنجکاوی بگذرونش**
>
> **Claude Code 101**: دوره‌ی coding agent برای developer‌ها؛ آدم‌هایی که کدنویسی بلد نیستن هم باهاش ابزار کوچیک می‌سازن.
>
> ⏱️ حدود یه ساعت و نیم · ➕ اختیاری · 🏅 دوره‌ی رایگان، با یه quiz و یه نشان
>
> اگه می‌گذرونی، تمومش کن و بعد برگرد این‌جا و ادامه بده. اگه نمی‌گذرونی، برو سراغ دوره‌ی بعدی.
>
> **[رفتن به دوره‌ی Claude Code 101](https://academy.claude.com/courses/claude-code-101)**

[Claude Code 101](https://academy.claude.com/courses/claude-code-101) کار با Claude Code رو یاد می‌ده. Claude Code یه agent‌ه که توی یه پنجره‌ی متنی به اسم terminal باهاش حرف می‌زنی. برای نوشتن نرم‌افزار ساخته شده و این دوره هم برای developer‌ها نوشته شده.

واسه همین، اگه engineer نیستی این دوره اختیاریه. ولی به نظر ما ارزش یه نگاه رو داره: چیزی رو که می‌خوای با زبون ساده توضیح می‌دی، و Claude Code خودش کدش رو می‌نویسه و برات اجراش می‌کنه. آدم‌هایی که هیچی از کدنویسی سر در نمیارن هم ازش استفاده می‌کنن تا ابزارهای کوچیک بسازن، spreadsheet‌ها رو مرتب کنن و کارهای تکراری و خسته‌کننده رو خودکار کنن. خود دوره فرض می‌کنه یه کم با code editor و command line آشنایی. یه پلن پولی Claude یا یه API key لازم داره.

## Introduction to Claude Cowork

> [!IMPORTANT]
> **🛑 دوره‌ی سوم از سه تا: همین‌جا وایسا و الان بگذرونش**
>
> **Introduction to Claude Cowork**: کار کردن Claude با فایل‌ها، پوشه‌ها و اپ‌های روی کامپیوترت.
>
> ⏱️ حدود دو ساعت و نیم · ✅ الزامی · 🏅 دوره‌ی رایگان، با یه quiz و یه نشان
>
> دوره رو باز کن، تمومش کن، بعد برای خلاصه برگرد این‌جا.
>
> **[رفتن به دوره‌ی Introduction to Claude Cowork](https://academy.claude.com/courses/introduction-to-claude-cowork)**

اگه کد نمی‌نویسی، بعد از Claude 101 این دوره رو بگذرون. **Claude Cowork** یعنی Claude مستقیم با فایل‌ها، پوشه‌ها و اپ‌های روی کامپیوترت کار کنه، و بخشی از همون اپ معمولی Claude‌ه. کار رو تو شروع می‌کنی: یه هدف بهش می‌دی، مثلاً «این فاکتورها رو توی پوشه‌ها مرتب کن و یه خلاصه برام دربیار». Claude یه برنامه می‌ریزه، قدم‌ها رو انجام می‌ده، و تو هم وسط کار می‌تونی هدایتش کنی. آخرش یه نتیجه‌ی واقعی دستت میاد، مثل یه گزارش، یه spreadsheet یا یه پوشه‌ی مرتب.

[Introduction to Claude Cowork](https://academy.claude.com/courses/introduction-to-claude-cowork) یادت می‌ده این جور کارها رو بسپری بهش. Claude رو توی Chrome، Word، Excel، PowerPoint و Outlook هم نشونت می‌ده، و این‌که قبل از اعتماد به کارش چطور چکش کنی. لازم نیست کدنویسی بلد باشی؛ یه پلن پولی Claude لازم داری، و برای درس‌هایی که با پوشه‌های کامپیوترت کار می‌کنن، اپ دسکتاپ Claude. حدود دو ساعت و نیم طول می‌کشه.

(Cowork رو با **Claude Duet** قاطی نکن. توی Cowork کار رو تو شروع می‌کنی. توی Duet، خود Claude شروعش می‌کنه: حواسش به اپ‌هایی که بهش وصل کردی هست، پشت صحنه کار انجام می‌ده، و هر روز صبح با یه خلاصه‌ی کوتاه میاد سراغت.)

## خلاصه

کار کردن با یه AI agent رو با کار کردن باهاش یاد می‌گیری. با Claude 101 شروع کن. بعد Introduction to Claude Cowork رو بگذرون که یه agent رو یادت می‌ده که با فایل‌ها و اپ‌هات کار می‌کنه. Claude Code 101 برای تو اختیاریه. خود دوره برای developer‌ها نوشته شده، ولی ابزاری که یاد می‌ده، یعنی Claude Code، به آدم‌هایی که کدنویسی بلد نیستن هم کمک می‌کنه چیزهای کوچیک بسازن.
