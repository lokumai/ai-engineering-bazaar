# Agent‌ها در عمل

یه AI agent فقط به سؤالت جواب نمی‌ده؛ برات کار هم انجام می‌ده. فایل باز می‌کنه، سند می‌نویسه، توی اینترنت می‌گرده و از اپ‌هات استفاده می‌کنه، قدم‌به‌قدم، تا وقتی که یه کار تموم بشه. می‌تونی کلی درباره‌ی agent‌ها بخونی، ولی سریع‌ترین راه برای فهمیدنشون اینه که یه کار واقعی بدی دست یکی‌شون و ببینی چی کار می‌کنه.

## چرا این دوره‌ها رو بگذرونی

وقتی درباره‌ی یه agent می‌خونی، همه‌چی خوب پیش می‌ره. ولی وقتی باهاش کار می‌کنی، بعضی وقت‌ها منظورت رو اشتباه می‌فهمه یا راه رو کج می‌ره، و اون‌وقت تو باید متوجه بشی و برش گردونی سر راه. مهارت اصلی همینه، و فقط با تمرین یاد گرفته می‌شه.

سه تا دوره‌ی پایین رایگان و کوتاهن، و با انجام دادن یاد می‌گیری. همون شرکتی که این ابزارها رو ساخته نوشتنشون، و ته هر کدوم یه quiz کوتاه و یه نشان (badge) هست.

هر سه‌تاشون از ![](../images/logos/claude.svg)**Claude** استفاده می‌کنن، دستیار هوش مصنوعی‌ای که Anthropic ساخته. ما فکر می‌کنیم الان، موقع نوشتن این متن، برای این جور کارها از همه توانمندتر، قابل‌اعتمادتر و پرامکانات‌تره. هر چی هم باهاش یاد بگیری، با بقیه‌ی دستیارهای هوش مصنوعی هم به کارت میاد.

## Claude 101

[Claude 101](https://academy.claude.com/courses/claude-101) جاییه که همه باید ازش شروع کنن. نشونت می‌ده Claude رو چطور توی کارهای روزمره‌ت به کار ببری: اولین گفت‌وگوت، این‌که چطور بپرسی تا جواب بهتری بگیری، و این‌که چطور سندها و دستورهای مربوط به یه کار رو توی یه project کنار هم نگه داری. این رو هم نشون می‌ده که Claude چطور به ابزارهایی که الان ازشون استفاده می‌کنی وصل می‌شه.

یه حساب Claude لازم داری؛ پلن رایگان هم کافیه و هیچ تجربه‌ای با هوش مصنوعی لازم نیست. حدود دو ساعت و نیم طول می‌کشه.

## Claude Code 101 (اختیاری)

[Claude Code 101](https://academy.claude.com/courses/claude-code-101) کار با Claude Code رو یاد می‌ده. Claude Code یه agent‌ه که توی یه پنجره‌ی متنی به اسم terminal باهاش حرف می‌زنی. برای نوشتن نرم‌افزار ساخته شده و این دوره هم برای developer‌ها نوشته شده.

واسه همین، اگه engineer نیستی این دوره اختیاریه. ولی به نظر ما ارزش یه نگاه رو داره: چیزی رو که می‌خوای با زبون ساده توضیح می‌دی، و Claude Code خودش کدش رو می‌نویسه و برات اجراش می‌کنه. آدم‌هایی که هیچی از کدنویسی سر در نمیارن هم ازش استفاده می‌کنن تا ابزارهای کوچیک بسازن، spreadsheet‌ها رو مرتب کنن و کارهای تکراری و خسته‌کننده رو خودکار کنن. یه پلن پولی Claude لازم داره.

## Introduction to Claude Cowork

اگه کد نمی‌نویسی، بعد از Claude 101 این دوره رو بگذرون. **Claude Cowork** یعنی Claude مستقیم با فایل‌ها، پوشه‌ها و اپ‌های روی کامپیوترت کار کنه، و بخشی از همون اپ معمولی Claude‌ه. کار رو تو شروع می‌کنی: یه هدف بهش می‌دی، مثلاً «این فاکتورها رو توی پوشه‌ها مرتب کن و یه خلاصه برام دربیار». Claude یه برنامه می‌ریزه، قدم‌ها رو انجام می‌ده، و تو هم وسط کار می‌تونی هدایتش کنی. آخرش یه نتیجه‌ی واقعی دستت میاد، مثل یه گزارش، یه spreadsheet یا یه پوشه‌ی مرتب.

[Introduction to Claude Cowork](https://academy.claude.com/courses/introduction-to-claude-cowork) یادت می‌ده این جور کارها رو بسپری بهش. Claude رو توی Chrome، Word، Excel، PowerPoint و Outlook هم نشونت می‌ده، و این‌که قبل از اعتماد به کارش چطور چکش کنی. لازم نیست کدنویسی بلد باشی؛ یه پلن پولی Claude و اپ دسکتاپ Claude لازم داری. حدود دو ساعت و نیم طول می‌کشه.

(Cowork رو با **Claude Duet** قاطی نکن. توی Cowork کار رو تو شروع می‌کنی. توی Duet، خود Claude شروعش می‌کنه: حواسش به اپ‌هایی که بهش وصل کردی هست، پشت صحنه کار انجام می‌ده، و هر روز صبح با یه خلاصه‌ی کوتاه میاد سراغت.)

## خلاصه

کار کردن با یه AI agent رو با کار کردن باهاش یاد می‌گیری. با Claude 101 شروع کن. بعد Introduction to Claude Cowork رو بگذرون که یه agent رو یادت می‌ده که با فایل‌ها و اپ‌هات کار می‌کنه. Claude Code 101 برای تو اختیاریه، ولی نشونت می‌ده که بدون بلد بودن کدنویسی هم می‌شه چیز ساخت.
