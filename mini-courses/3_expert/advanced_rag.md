# Advanced RAG & Embeddings

*(Placeholder module: a short overview for now, full lesson content is coming soon.)*

RAG & Embeddings built the simplest pipeline that works: chunk, embed, search, answer. This module covers what changes when that pipeline has to work well on real documents, and the choices behind every step of it.

**Topics this module will cover**:
- RAG vs. long context vs. fine-tuning
- Ingesting data
- Chunking strategies: fixed size, sliding window, recursive, document-based and semantic chunking
- Indexing hyperparameters
- Retrieval: semantic search, BM25, or both, and a reranker (a cross-encoder) after it
- Bi-encoder vs. cross-encoder
- Hybrid retrieval
- Contextual retrieval, from Anthropic
- Correct vs. faithful
- Architectures: naive RAG, HyDE, corrective RAG, multi-hop RAG, GraphRAG, agentic RAG and multimodal RAG
- RAG security
