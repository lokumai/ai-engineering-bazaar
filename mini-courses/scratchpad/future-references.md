## Module 11: Harness Engineering

- [Writing effective tools for AI agents](https://www.anthropic.com/engineering/writing-tools-for-agents)
  (Anthropic, 2025-09-11). How to design a tool an agent can actually use: fewer tools rather than
  one per API endpoint, namespaced names, responses that return meaning instead of identifiers,
  pagination so a result cannot flood the window, and tool descriptions treated as prompt
  engineering. Also argues for evaluating tools on real tasks rather than assuming they work.
