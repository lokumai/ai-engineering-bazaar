Three words are worth deciding separately, whichever set you pick, because each one carries a claim rather than a label.

Complete vs Mark as read. Today the button asserts you read it and met the objectives. If it stays self-asserted, Mark as read is the honest word and nobody expects a test. If it should mean something stronger, Complete earns it.

Level is used twice in Set C: the level of the curriculum (Fundamentals) and the rank of the reader. Pick one. I would keep Level for the curriculum and use Rank for the person, because the curriculum's levels are on every screen and the rank is on one.

Turkish. Set C survives translation best: Seviye, Modül, Tamamla, Gereksinimler. Set A's Section and Set B's Part both collapse to Bölüm, which already means chapter, section and part, so the hierarchy would go flat in Turkish.
