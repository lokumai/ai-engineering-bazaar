The kinds, and their emoji

Five kinds cover every reference in the three lists read for this page. A course is rare, so it shares 📚 with lists rather than adding a sixth emoji. When an item has two links, its kind is the kind of the first one. J2 and J3 use the same five kinds as words.

  • 📄Articlea written post, a paper, or a docs pageA screen reader says “page facing up”
  • 🎬VideoYouTube, Shorts, a recorded talkA screen reader says “clapper board”
  • 🧰Tool or librarya GitHub repository, a library, a productA screen reader says “toolbox”
  • 📚List or coursea list of resources, or a courseA screen reader says “books”
  • 🧭Module of this courseanother module of this courseA screen reader says “compass”

One emoji at the start of each item

Recommended

The list stays as it is, in the order you wrote it. Each item gets one emoji between the bullet and the link, outside the brackets, so the link text is still only the title.

  • Nothing else changes: same order, same list, no new headings. The emoji is the same character in English, Turkish and Persian, so a translation never has to translate it.
  • Reads the same on GitHub, in VS Code, on a phone and right to left. Five emoji to learn, and the link next to each one confirms it (a youtube.com link next to 🎬).
  • Costs: a screen reader says the emoji name before every link ("page facing up"). The site can read "Article" there instead without touching the markdown; GitHub cannot.

Why this one: it tells the kinds apart with one character per line and changes nothing else, in any viewer and any of the three languages.

Small groups, each under a short heading

The list is split into groups by kind, each under a ### heading inside References. Items keep your order inside their group.

  • The kind is a word, so it reads well to everyone, screen readers included, and a reader looking for videos goes straight to the group.
  • Costs: five headings at the bottom of every page, each with its own § link. The order you chose across kinds is lost, and short lists end up with groups of one (Observability has 6 references in 3 kinds).
  • Five heading words to keep identical in three languages across every module.
