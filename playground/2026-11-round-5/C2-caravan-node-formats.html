Formats

Each stop is a trend, not a release: something the field was talking about for a season or longer. The sample trends below are high level on purpose.

What each field costs

Every field is something a person has to find or write for each trend, for as long as Caravan is kept up. A filled disc is needed, a ring is optional, a dashed ring is derived by the build, a dash is not used.

Grain: how often a stop appears

The same sample trends, three ways, over the same land. Each strip scrolls sideways inside itself; point at or Tab to a stop to name it.

Intensity: what makes the land rise

N3 and N4 carry an intensity, and every C1 design draws its hills from it. It is only worth having if the same rule makes it every month.

H1

The editor's rubric

A person scores each trend 1 to 5 against a short written rubric kept beside the data.

CostsOne judgement a trend. Cheap, and it drifts unless the rubric is reread each time.

H2

How widely it was carried

Count how many of a fixed set of source types covered it: company posts, papers, GitHub trending, news, social posts, blogs.

CostsA fixed list of places to check. Repeatable, and N4's typed sources are already its evidence.

H3

A measured signal

A number someone else publishes, such as stars gained on GitHub or search interest, put into five buckets.

CostsA script and an archive, since a past month cannot be measured later. The least work by hand and the most to build.
